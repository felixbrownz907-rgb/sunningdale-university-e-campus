# Sunningdale University E-Campus Portal

A modern web-based student and e-campus portal built for managing academic resources, user authentication, and interactive campus services.

## 🚀 Tech Stack
* **Frontend:** React, JavaScript, HTML5, CSS3
* **Build Tool:** Vite
* **Version Control:** Git & GitHub

## 📁 Project Structure
* `public/` - Static assets, images, and the application logo.
* `src/` - React components, views, and core application logic (including user authentication).
* `index.html` - Main HTML entry point.
* `package.json` - Project dependencies and scripts.
* `vite.config.js` - Vite configuration file.
